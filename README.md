# SpinTimer

スピンバイク向けのワークアウトタイマー。RPMに合わせたビート音とオービタルアニメーションで、ペダルのリズムをガイドします。

## デモ

https://fersimius.github.io/spin-timer/

## 機能

- **3フェーズ構成** — ウォームアップ → ピーク → クールダウンを時間指定で自動遷移
- **RPM連動ビート** — クリック音 / トーン音から選択。音量調整可
- **オービタルアニメーション** — RPMに同期した彗星風の軌道表示
- **PWA対応** — iPhoneの「ホーム画面に追加」でアプリとして動作
- **Wake Lock** — タイマー中は画面の自動ロックを防止
- **ワークアウト履歴** — 過去30件の記録をローカル保存。スワイプで個別削除可
- **横画面対応** — ランドスケープ表示に自動切替

## 使い方

1. Peak RPM・時間・ウォームアップ/クールダウンを設定
2. **START** でワークアウト開始
3. ビート音に合わせてペダリング
4. 終了後にリザルト画面を表示

## インストール（PWA）

iPhone Safari でページを開き、共有ボタン →「ホーム画面に追加」。  
スタンドアロンアプリとして起動します。

## 技術スタック

- HTML / CSS / JavaScript（フレームワークなし、単一ファイル構成）
- Web Audio API（ビート音生成）
- Screen Wake Lock API（自動ロック防止）
- CSS conic-gradient（オービタルアニメーション）
- localStorage（設定・履歴の保存）
